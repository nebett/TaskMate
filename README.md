# TaskMate — One Place for All Your College Tasks

Aplikasi pengelolaan tugas akademik untuk mahasiswa D3, D4, dan S1.
React Native + Expo + TypeScript + Expo Router + AsyncStorage.

## Menjalankan

```bash
npm install
npx expo start        # tekan "w" untuk web, scan QR dengan Expo Go untuk Android
```

## Catatan

- Layout adaptif: bottom navigation (HP) dan sidebar (layar >= 900px).
- Tema Terang / Gelap / Sistem, tersimpan otomatis.
- Notifikasi sistem hanya aktif pada development build / APK (bukan Expo Go atau web).
  Pengingat di dalam aplikasi selalu aktif.
